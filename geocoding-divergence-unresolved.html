What “unresolved” means

When Google Maps and the source coordinate (Vera Institute, Marshall Project, or the project’s own geocoding) differ by more than 3 km, build_geocoded_all() refuses to pick a side: the facility’s final lat/lon are left NA and the case is flagged for human review. Resolution means adding the facility’s DETLOC to the appropriate group in geocode_source_preference() (R/geocode.R) — google_maps, vera_institute, marshall_project, or manual — and rerunning the pipeline.

Hold rooms (IDs 2026–2189) are excluded from this copy. Their Marshall coordinates are a separate, larger backlog — they remain visible in the main divergence report.

Operational context

Presence in the FY26 annual-stats panel and/or DDP daily population data, with best-available peak ADP, to gauge which divergences matter most.

Code 
facility_presence <- tar_read(facility_presence)
source_presence <- tar_read(source_presence)
facilities_panel <- tar_read(facilities_panel)
ddp_fy25_summary <- tar_read(ddp_fy25_summary)
detloc_lookup <- tar_read(detloc_lookup)

fy26_ids <- facility_presence |> filter(FY26) |> pull(canonical_id)
ddp_ids  <- source_presence |> filter(in_ddp) |> pull(canonical_id)

peak_adp_panel <- facilities_panel |>
  group_by(canonical_id) |>
  summarise(peak_adp_panel = max(adp, na.rm = TRUE), .groups = "drop") |>
  mutate(peak_adp_panel = ifelse(is.infinite(peak_adp_panel), NA_real_, peak_adp_panel))

ddp_adp <- ddp_fy25_summary |>
  inner_join(detloc_lookup, by = c("detention_facility_code" = "detloc")) |>
  group_by(canonical_id) |>
  summarise(
    ddp_adp  = max(adp_total, na.rm = TRUE),
    ddp_peak = max(peak_population, na.rm = TRUE),
    .groups = "drop"
  )

unresolved_classified <- unresolved |>
  mutate(
    in_fy26 = canonical_id %in% fy26_ids,
    in_ddp  = canonical_id %in% ddp_ids,
    presence = case_when(
      in_fy26 & in_ddp  ~ "Both FY26 + DDP",
      in_fy26 & !in_ddp ~ "FY26 only",
      !in_fy26 & in_ddp ~ "DDP only",
      TRUE               ~ "Neither"
    )
  ) |>
  left_join(peak_adp_panel, by = "canonical_id") |>
  left_join(ddp_adp, by = "canonical_id") |>
  mutate(best_peak_adp = coalesce(peak_adp_panel, ddp_peak))

Notes on individual cases

Migrant Ops Center Main A (404) — 662 km

The largest divergence by two orders of magnitude. The facility’s address is an APO/FPO routing address (“Avenue C Psc 1005 Box 55, FPO FL”), which Google resolves to a default mainland-Florida location (26.7°N, 80.9°W, near Port St. Lucie). Vera’s coordinate (21.5°N, 77.8°W) is the actual Guantánamo Bay site. The Vera coordinate is correct; resolving this case means adding GTMODCU to the vera_institute group in geocode_source_preference().

The county-jail cluster (3–16 km)

The remaining cases are all mainland jails, prisons, and medical facilities where Vera and Google disagree by 3–16 km — typically rural-address geocoding differences, campus-boundary ambiguity, or a stale Vera address. Each needs an individual check of which coordinate lands on the actual facility.

Five roster facilities have neither an accepted coordinate nor enough address data to geocode. These need address research (not a source-preference decision); several are DDP-era stubs.
